# GHG Emissions Predictor

A machine learning project that predicts Greenhouse Gas (GHG) 
emissions from US supply chain industries and commodities using 
Logistic Regression.

## About
Built using real EPA supply chain emission factor data, this project 
trains an ML model to classify and predict GHG emission levels across 
different US industries — directly aligned with Green Skills and 
sustainability initiatives.

## Tech Stack
- Python, Jupyter Notebook
- Scikit-learn (Logistic Regression)
- Pandas, NumPy
- Pickle (model serialization)
- Flask (app.py for deployment)

## Dataset
EPA Supply Chain Emission Factors for US Industries & Commodities

## How to Run
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Open `ghg.ipynb` in Jupyter Notebook
4. Run `python app.py` to launch the web app
